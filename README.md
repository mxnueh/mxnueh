## Who I am

I'm Enmanuel Nunez Matias, a Full Stack Developer and Systems Designer from Santo Domingo, Dominican Republic. I've been building web applications since 2024, with React, TypeScript and Tailwind CSS on the frontend and Python (Flask) with SQL databases on the backend. I'm studying Software Development at ITLA (Instituto Tecnológico de Las Américas) and working as a freelancer on client projects.

What drives me is taking an idea all the way through: understanding the problem, designing the system, and shipping something that actually works. I care about clear code and practical solutions. I don't focus on learning tools for the sake of it; I focus on **using them to build solutions**.

Along the way I've been a finalist in four hackathons, two of them NASA challenges, and I contribute to open source through omegaUp as part of Google Summer of Code 2026.

## What I do

I build full-stack applications and the systems behind them: a usable interface, a solid backend, and, when the problem calls for it, real hardware.

- **Frontend.** React, TypeScript, Tailwind CSS and Bootstrap. Responsive interfaces, designed first in Figma when the UX needs thought.
- **Backend and data.** REST APIs with Python and Flask, PostgreSQL and Supabase, JWT authentication and role-based access control (RBAC).
- **Quality and delivery.** Git workflows, code reviews, unit testing and CI/CD with GitHub Actions, deploying on Vercel.
- **Hardware and telemetry.** ESP32, Raspberry Pi and sensors, connected to software that people can read and trust.
- **AI-assisted development.** I use AI coding agents to move faster, and I review every change by hand.

**My toolbox:** React · TypeScript · JavaScript · Tailwind CSS · Python · Flask · Node.js · PostgreSQL · Supabase · Git · GitHub Actions · Vercel · Figma

**Also:** C# · C++ · PHP · MySQL · SQL Server

### Selected work

**Real estate CRM** (freelance, 2026). A Supabase-backed CRM built with React, TypeScript and Tailwind CSS, in production on Vercel. It shipped five modules: payment registration with amortization tables, PDF receipts, client document uploads, a notes history and a Kanban pipeline.

**Driving-education platform** (freelance, 2026). I worked on the Flask and PostgreSQL REST API with a team of four. We added GitHub Actions gates that enforce PEP 8, black, flake8 and 80% minimum test coverage, and I shipped email-based two-factor authentication and JWT refresh tokens with rate limiting.

**Document management platform** (Inspectoría Salesiana de las Antillas, Oct 2024 – Jul 2025). I analyzed the existing workflows and led the system design in Python and Flask, consolidating resources and documents into one centralized web platform. I implemented RBAC for granular permissions, designed the relational schema, and redesigned the UI/UX in Figma.

**[SkyGuard](https://github.com/mxnueh/DemoApp)** (NASA Space Apps Challenge 2025, finalist). An interactive web app that visualizes air pollution using NASA Earth data, with a calculator of the trees needed to cut annual pollution by 40% and a way to spot vulnerable areas from wind patterns. The [landing page](https://github.com/mxnueh/Data-Earth-II) is in its own repo.

**[Floppy](https://github.com/mxnueh/floppy)** (CreaRD Technological Innovation Hackathon 2025, finalist, 4th place). An IoT early-warning system for floods. Together with the team, I designed a modular architecture with an ESP32 and dual water level sensors, a Python/Flask backend, and a web dashboard with multi-channel alerts by email, WhatsApp and push notifications. I was the Full Stack Developer on the team.

**AstroBosco rover** (NASA Human Exploration Rover Challenge 2025, finalist). I was the telemetry department manager, in charge of the rover's programming and of turning raw sensor data into information a person can read on an interface. Part of that code lives in [Raspberry-Pi](https://github.com/mxnueh/Raspberry-Pi).

**omegaUp** (open source, Google Summer of Code 2026). I fixed a UI defect with tab overflow (issue #9454), replacing custom CSS with Bootstrap utility classes and incorporating the maintainer's code-review feedback into the final fix.

The rest of my work is in my [repositories](https://github.com/mxnueh?tab=repositories).
