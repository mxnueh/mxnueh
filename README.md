## Who I am

I'm Enmanuel Nunez Matias, a Full Stack Developer and Systems Designer from the Dominican Republic. I'm studying Software Development at ITLA (Instituto Tecnológico de Las Américas) while building real projects, web and mobile, with a small development team that works with clients.

What drives me is taking an idea all the way through: understanding the problem, designing the system, and shipping something that actually works. I care about clear code and practical solutions. I don't focus on learning tools for the sake of it; I focus on **using them to build solutions**.

## What I do

I build full-stack applications and the systems behind them. Most of my work sits between a clean backend, a usable interface, and, when the problem calls for it, real hardware.

- **Backend and systems.** APIs and data-driven apps with Python (Flask, FastAPI), SQL Server and MySQL.
- **Web and mobile.** Interfaces built with React, TypeScript, JavaScript, HTML and CSS.
- **Automation.** Turning repetitive, manual processes into something that runs on its own.
- **Hardware and telemetry.** Connecting sensors, microcontrollers and Raspberry Pi to software that people can read and trust.

**My toolbox:** Python · JavaScript · TypeScript · C# · C++ · React · Flask · FastAPI · Node.js · PHP · SQL Server · MySQL · Git · Linux

### Some of the things I've built

- **[Floppy](https://github.com/mxnueh/floppy)**: an IoT flood monitoring and alert system. An ESP32 with ultrasonic sensors reads the water level, a Python/Flask backend exposes it through REST APIs, and a web interface shows it. I was the Full Stack Developer on the team, and we placed 4th at the CreaRD hackathon.
- **SkyGuard** ([demo](https://github.com/mxnueh/DemoApp) · [landing page](https://github.com/mxnueh/Data-Earth-II)): our project for the NASA Space Apps Challenge 2025, an air quality map with a reforestation calculator.
- **AstroBosco rover, NASA HERC 2025**: I was the telemetry department manager, in charge of the rover's programming and of turning raw sensor data into information a person can read on an interface. Part of that code lives in [Raspberry-Pi](https://github.com/mxnueh/Raspberry-Pi).
- **[POI](https://github.com/mxnueh/POI)**: an institutional portal in PHP and MySQL, with login and separate panels for administrators and users.

The rest of my work is in my [repositories](https://github.com/mxnueh?tab=repositories).

## Vision

My dream career is software engineer, and I want to grow along the whole path: from shipping features, to designing architectures, to leading teams. I plan to get there the way I've learned so far: courses, workshops, hackathons, certifications, and above all by building things.

I believe good systems are simple ones that solve real problems. I'm especially drawn to problems close to home in the Dominican Republic, like flooding, where a few well-placed sensors and clear software can make a difference.

## Beyond code
